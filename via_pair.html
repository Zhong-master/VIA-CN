Some Quick Tips

  • This demo shows how the VIA3 application can be used to define attributes of an image pair.
  • The images were included using a hyperlink to Wikimedia Commons. Here are the links to the original wikimedia commons source:
    • Balloon over Luxor - Egypt denoised.jpg
    • Castillo de Montuenga, Montuenga de Soria, Soria, España, 2017-05-23, DD 04.jpg
    • Paradise shelduck portrait, New Zealand.jpg
    • Red-billed oxpecker (Buphagus erythrorhynchus) on impala (Aepyceros melampus).jpg
  • 开始标注图片、音频和视频，请选择 本地文件 或 添加文件（本地文件用 file://，远程文件用 http:// 地址）。也可以在 批量 中添加文件地址列表。
  • 随时按 空格 键播放或暂停音频或视频。
  • 当视频暂停时，可以为图片和视频帧定义空间区域（例如 50x80 像素的矩形边界框）。也可以为音频和视频文件定义时间片段（例如从 3.1 秒到 12.5 秒的视频片段）。
  • 使用 属性编辑器 定义或更新用户区域的属性（例如名称、颜色等）。
  • 你也可以尝试预加载的 图片、音频 和 视频 标注演示。
